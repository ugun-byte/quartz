# Editorial Rules

Signal Cabinet의 모든 자동 요약과 Quartz Markdown 생성은 아래 규칙을 따릅니다.

## 필수 규칙

1. **원문 의미를 왜곡하지 않는다.**
   - 발언의 의미, 맥락, 뉘앙스를 임의로 바꾸지 않습니다.
   - 확실하지 않은 내용은 단정하지 않고 불확실하다고 표시합니다.

2. **과장된 해석을 하지 않는다.**
   - 원문에 없는 의도, 전망, 파급효과를 붙이지 않습니다.
   - “세상을 바꿀”, “폭발적 상승”, “게임체인저 확정” 같은 과장 표현은 피합니다.

3. **투자 판단처럼 보이는 문장은 피한다.**
   - 매수, 매도, 수익 가능성, 가격 예측처럼 보이는 표현을 쓰지 않습니다.
   - 기업/시장 관련 발언도 정보 정리 수준으로만 다룹니다.

4. **분야별로 정리한다.**
   - 정치·공공, AI, 테크·IT, 투자·경제, 로봇·미래기술, 미디어·콘텐츠 등으로 묶습니다.

5. **각 인물별로 내용을 사실대로 정리한다.**
   - 인물별 발언, 공유, 링크, 맥락을 섞지 않고 분리합니다.
   - 원문에 없는 의견을 해당 인물의 입장처럼 쓰지 않습니다.

6. **중요한 글은 주목도로 표시한다.**
   - `주목도: 높음`
   - `주목도: 중간`
   - `주목도: 낮음`

7. **Quartz Markdown 형식으로 출력한다.**
   - frontmatter, 제목, 분야별 heading, 인물별 subsection, 태그를 포함합니다.

8. **원문 링크를 반드시 남긴다.**
   - 모든 인물별 요약 항목에는 X.com 원문 링크 또는 확인 가능한 원문 링크를 포함합니다.

## 주목도 기준

### 높음

- 공식 발표, 정책, 제품, 연구 방향 변화가 직접 드러나는 글
- 여러 분야에 파급될 수 있는 새 정보가 포함된 글
- 당일 브리핑의 핵심 신호로 볼 만한 글

### 중간

- 분야 흐름을 이해하는 데 도움이 되는 글
- 기존 입장이나 활동을 보강하는 글
- 관련 인물/기관과의 연결성이 있는 글

### 낮음

- 단순 반응, 인사, 행사 공유, 반복적 홍보성 글
- 기록 가치는 있지만 핵심 신호는 약한 글

## 적용 파일

규칙 원본은 아래 파일에서 관리합니다.

```text
data/editorial-rules.yaml
```

Markdown 생성기는 아래 스크립트에서 주목도와 원문 링크 형식을 강제합니다.

```text
scripts/generate-briefing.mjs
```
